Mera personal WhatsApp number lagana padega? ▾

Behtar hai shop ke liye alag number use karo. Aap apna normal WhatsApp alag rakh sakte ho — BudsBox sirf us number ko use karta hai jo aap Meta Cloud API me jodte ho.

Connect / disconnect karna mushkil hai? ▾

Nahi. Dashboard ke WhatsApp tab me Phone number ID aur token paste karke "Save & connect" dabao. Kabhi band karna ho to wahi "Disconnect" button — ek click, turant AI ruk jata hai.
